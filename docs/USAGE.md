# 使用说明

## 一、它是什么

一个**不需要 root** 的独立 App，在屏幕上挂一个小胶囊，实时显示你在网易云听了多久。

它靠系统公开权限工作：监听媒体会话读取播放状态，用悬浮窗把数据画出来。不注入任何进程，不修改任何 App。

---

## 二、安装（三步，缺一不可）

### ① 授予悬浮窗权限

```
打开 NCM Lite
→ 点「① 授予悬浮窗权限」
→ 系统设置里找到「显示在其他应用上层」→ 允许
```

**没有它**：胶囊画不出来，但后台计时照常。

### ② 授予通知使用权

```
点「② 授予通知使用权」
→ 系统设置 → 通知使用权 → 找到「NCM Lite」→ 打开
```

**没有它**：读不到网易云的播放状态，胶囊永远是 0。

这是整个 App 的命门。`MediaSessionManager.getActiveSessions()` 必须要有这个权限才允许调用。

### ③ 启动胶囊

```
点「③ 启动悬浮胶囊」
→ 回到桌面，胶囊出现
```

界面上会实时显示两个权限的状态：

```
✅ 悬浮窗权限
✅ 通知使用权
```

两个都是 ✅ 才算配好。

## 三、胶囊操作

| 手势 | 动作 |
|---|---|
| **单击** | 切换显示：总时长 ↔ 今日累计 |
| **双击** | 下一首 |
| **长按** | 弹出菜单 |
| **拖动** | 换位置 |

### 显示内容

| 模式 | 显示 | 说明 |
|---|---|---|
| 总时长 | `12.3h` 或 `738m` | 累计听歌时长（单位可在菜单里切） |
| 今日 | `2h35m` | 今天听了多久 |

### 视觉

- **背景填充** = 当前歌曲的播放进度
- **左侧竖条** = 亮＝播放中，暗＝暂停
- **切歌光扫** = 换歌时有一道光扫过

## 四、菜单（13 项）

长按胶囊弹出：

| 菜单项 | 作用 | 点完关菜单？ |
|---|---|---|
| **显示单位：小时 / 分钟** | 切换显示单位 | ❌ 不关，可连点 |
| **形状：胶囊 / 超椭圆 / 不对称 / 方角** | 四种轮廓 | ❌ 不关 |
| **尺寸：小 / 中 / 大 / 超大** | 整体等比缩放 | ❌ 不关 |
| **长度：短 / 标准 / 长 / 很长** | 横向拉伸（独立于尺寸） | ❌ 不关 |
| **切换动画：开 / 关** | 切换显示时的翻牌动画 | ❌ 不关 |
| **胶囊颜色** | 12 色板 | ✅ 关 |
| **自定义颜色（色相盘）** | 色相 + 亮度双条拖动 | ✅ 关 |
| **查看详情** | 打开数据卡片 | ✅ 关 |
| **刷新数字** | 手动刷新一次 | ✅ 关 |
| **上一首** | 上一首 | ✅ 关 |
| **播放 / 暂停** | 播放暂停切换 | ✅ 关 |
| **下一首** | 下一首 | ✅ 关 |
| **重置位置** | 回到右上角默认位置 | ✅ 关 |
| **关闭胶囊** | 停止服务 | ✅ 关 |

### 尺寸 × 长度的组合

这两个是独立的：

```
尺寸 = 整体比例（高度、字号、宽度一起变）
长度 = 额外横向 padding（只拉宽）

小 + 很长   → 矮而长的扁胶囊
超大 + 短   → 高而紧凑的方块
中 + 标准   → 默认，跟 root 版一模一样
```

### 色相盘

```
┌────────────────────┐
│   实时预览色块       │
├────────────────────┤
│ 上：色相 红→黄→绿→蓝 │
│ 下：亮度 暗→亮       │  ← 会跟着上面的色相重新着色
└────────────────────┘
松手确认
```

亮度范围 15% ~ 100%。

## 五、数据

全部在 `Android/data/io.whale.ncmlite/files/`：

| 文件 | 内容 |
|---|---|
| `records.jsonl` | 每段播放一条 JSON |
| `lite.log` | 运行日志 |

### 记录格式

```json
{"start":"2026-11-18 23:20:41","end":"2026-11-18 23:24:12",
 "title":"I-98","artist":"Hayd","duration_ms":215000,
 "played_ms":211000,"played_sec":211,"finished":true,"reason":"switch"}
```

`played_sec` 是实际播放时长，`finished` 是是否听完。

### 设置存在哪

`SharedPreferences` 里（`ncm_lite`），卸载 App 才会丢。累计时长、段数、形状、尺寸、颜色都在里面。

## 六、常见问题

**Q：胶囊不出现**
1. 悬浮窗权限给了吗（App 界面第一个 ✅）
2. App 里点过「③ 启动悬浮胶囊」吗
3. 看 `lite.log` 有没有 `badge add fail`

**Q：数字一直是 0.0h**
- 通知使用权没给（第二个 ✅）
- 或者网易云没在放歌
- 日志里应该有 `bound: com.netease.cloudmusic` 和 `NOW >> 歌名`

**Q：菜单点了没反应**
- 尺寸/形状/长度/单位/动画这五项是「连点式」，菜单不会关，文字会当场变
- 如果文字也没变，看日志有没有 `refresh layout fail`

**Q：数据准不准**
- 播放/暂停/切歌是准的
- 但如果网易云在后台不发状态回调，那一段只能靠切歌时补算，可能有 1~2 秒误差
- 这是免 root 的固有代价——要精确到毫秒，只能用 [NCM Archive](root 版)

**Q：会不会上传我的听歌数据**
- 不会。App 没有网络权限相关的任何代码，所有数据只写本地文件

**Q：怎么卸载干净**
```
1. App 里点「④ 停止」
2. 卸载 NCM Lite
3. 删掉 Android/data/io.whale.ncmlite/
```

## 七、和 root 版怎么选

```
只要一个能看的数字，不想折腾 root     → 用这个（NCM Lite）
要精确到毫秒、要自动取封面配色        → 用 root 版（NCM Archive）
两个都要                              → 别同时开，会看到两个胶囊
```
